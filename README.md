# Quản lý mẫu & công việc tại đại lý

Bản web (GitHub Pages) của app quản lý mẫu gạch / công việc tại đại lý.

- `index.html` — giao diện (tạo tự động từ `Code_app.html`).
- `config.js` — địa chỉ API Apps Script (`window.APP_API_URL`).
- Dữ liệu (giá, tồn kho, đại lý) **không nằm trong repo này**: app lấy qua API Apps Script sau khi đăng nhập bằng tài khoản riêng.
